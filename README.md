**OrbitAlert**

📱 Sobre o Projeto

O **OrbitAlert** é uma aplicação mobile desenvolvida em **Flutter** com foco em monitoramento climático e ambiental das regiões brasileiras. O aplicativo utiliza uma interface moderna e intuitiva para apresentar informações regionais, estados monitorados e eventos climáticos relevantes.

A proposta do projeto é demonstrar uma solução tecnológica voltada ao acompanhamento ambiental por meio de dados climáticos organizados por regiões do Brasil.

\-\--

🚀 Tecnologias Utilizadas

- Flutter

- Dart

- Material Design

- Lottie Animations

- Weather Icons

- Navegação com Rotas Nomeadas

- Arquitetura baseada em componentes reutilizáveis
